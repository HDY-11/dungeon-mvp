### 1.3 待用户拍板的问题（带我的推荐默认值，未拍板）

- **Q1 法杖的定位与槽位**：占主手还是副手/新槽？是施法前提（没杖不能施法）还是可选强化？品质如何转化为「额外 MP 投入上限」？
  - 选项：a) 主手工具，副手可盾；b) 副手，主手仍可武器（更宽容）；c) 新槽「法器」（最宽容，但改 UI/存档）。
  - 我的推荐：**b（副手）**——复用现有 Slot/Equippable 数据，不新槽；非施法前提，只给上限与加成。
- **Q2 MP 投入的操作**：每次施法是否要显示投入量？默认=基础消耗、可加投到法杖上限？超量投入线性还是边际递减？
  - 我的推荐：默认基础消耗、可加投到上限；收益边际递减（如每点额外 MP 只给 60%/40%…），系数待校准。
- **Q3 精通的角色**：加算进基础（当前做法）、乘算系数、还是加法封顶？来源是等级自动长、还是卷轴/装备/使用次数？
  - 我的推荐：**乘算系数**（精通→1+精通×k）；来源沿用等级+装备，暂不引入使用次数熟练度。
- **Q4 穿透**：属性词条（magic_penetration）还是法术/法杖自带？上限多少？确认作用点是 `护甲域×(1−穿透)`。
  - 我的推荐：先做成法术/法杖自带的小额穿透（0–30%），不新增全局属性。
- **Q5 法术暴击**：是否接入暴击域 (1+爆伤)？暴击率/爆伤用玩家的物理暴击还是单独法术暴击？
  - 我的推荐：**MVP 不做**。
- **Q6 敌方反制施法**：本轮 MVP 是否做？最轻是「施法被打断/被沉默」，最重是「敌方也会施法并反制」。
  - 我的推荐：MVP 只做「被打断」，敌方施法排后续。
- **Q7 两行现有法术数据**：火花术/治愈术保留并重做数值，还是直接按新体系重写？
  - 我的推荐：保留两个法术作为「入门锚点」，重做公式与数据。

### R3.1 层内区块系统（#11）评估备注（lead m00352）

- **现状边界**：`ecs_core/src/map` 是「一层 = 一张 80×60 `Map`（`[[Tile; 80]; 60]`）+ 单次生成器 + 楼梯」；FOV / 占用图 / 格效果 / 寻路 / 相机全按单图工作。
- **两条路线**：
  - 推荐：**每区块一张 Map + 连接口切图**——新增层内区块图与连接口；切图时按新区块重建 Map/占用/FOV/相机；单图系统基本不改。成本约 2–3 轮（区块图、连接口、切换入口、存档坐标）。
  - 不推荐：连续滚动——要换世界坐标系，渲染/相机/寻路/FOV/存档同时改，成本高一个数量级；第一章不做。
- **存档与层边界（关键）**：现 V5 只存 `map_seed + floor + 玩家状态`，地图按 (seed, floor) 确定性重放。区块化后：
  - 必须增存「当前区块坐标 + 区块图 seed」；每个区块的怪物/物品/事件 RNG 必须从 (seed, floor, cx, cy) 派生，不能沿用「每层一条 RNG 流」，否则进入区块顺序会改变内容、读档不可复现。
  - 若要「离开再回来保留状态」（怪死没死 / 东西捡没捡 / 门开没开）→ 需新增区块级 delta 存档（chunk_id + 变更）+ 区块卸载时实体休眠/回收，是第二个新存档层、工作量最大。
  - 若不要求状态保留（离开重置 / 只保留一次性开关）→ 存档只多两个坐标字段，≈零额外成本。**建议第一章先做这个**。
- **依赖排序**：区块系统先动地图生成与层切换入口（`world/floor.rs` 同级），其余系统保持「一次只看当前 Map」。环境伤害 / 危险格走 `CellEffectAt` 扩展，与区块化独立，可先做。
- **结论**：架构级 + 第一个新存档层；建议第一层内容定稿并出现「箱庭/多区块」实际需求后再立项；先做「换图 + 离开重置 + 每区块 RNG」，不做连续滚动与状态保留。
