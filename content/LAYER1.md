## 1. 地图与两群系

- **尺寸**：用户已澄清 255×255 指**区块尺寸**（80×60 只是一块区块）；见 `MAP_BLOCKS.md`——区块推荐 **128×128**，一块一个群系。v1.1 的 80×60 布局只作过渡，密度按 `MAP_BLOCKS.md` §7 重算。
- **落法**（lead 结论 R6-1）：深度分区 + 8–10 格过渡带，改 `map_gen`，**不做区块网**；fallback = 第一层只做「水蚀洞窟」，表层缩成入口竖井。
- 区块网（CONTENT §5.2 远景）**v1 不做**。

### 1.1 表层洞窟 `surface_cavern`

- **地形组合** [试调]：Floor 60% / Wall 28% / Stalactite 6% / Mycelium 3% / FungalPatch 3%；少量窄道与断层房间。
- **危险环境**：无环境伤害（v1 不做落石）；危险来自窄道伏击与兽人。
- **资源（v1 无材料）**：地面功能物品（锈铁剑教学/蘑菇/绷带）+ 叙事物（祭坛）。
- **栖息生物**：巨鼠群、岩壳兽、兽人斥候；菌人（中立素材，少见）。
- **出现规则**：出生区；前半张地图不出现精英；兽人营地与层尾之门在其尽头。
- **氛围**：干燥、闷热，脚下是碎骨与旧血；远处有节拍一样的敲击声——那是兽人在挖矿。

### 1.2 水蚀洞窟 `water_eroded_cavern`

- **地形组合** [试调]：Floor 35% / ShallowWater 25% / DeepWater 8% / Wall 22% / Seagrass 5% / CoralReef 3% / Mycelium 2%。
- **危险环境**：浅水移速 ×1.5；深水阻挡移动与视线；泥潭 ×2 移速（可选 6 处）。
- **资源（v1 无材料）**：功能性物品（蘑菇/绷带/武器）+ 地下泉。
- **栖息生物**：结网蛛、孢子行者、岩壳兽（边缘）、兽人斥候、菌人（中立素材）。
- **出现规则**：地图深处；穴居蛛/史莱姆密度随距离上升；地下泉、捷径在此。
- **氛围**：水声、滴冰；洞顶倒挂的蛛网像旧布。踩进浅水的声音会传出很远。

## 4. 效果（v1 四种）

| 效果 | 来源（v1） | 触发 | 时长 | 叠层 | 吃哪几域 | 状态 |
|---|---|---|---|---|---|---|
| `poison` 中毒 | 穴居蛛毒牙 | 命中 | 1200 AV（400×3 跳） | 刷新不叠 | 只吃魔法抗性 | **复用**（现有 `poison_tick`） |
| `slow_move` 迟缓 | 穴居蛛蛛网 / 史莱姆黏液 / 食肉藤缠绕 | 命中 | 2400 AV | 刷新不叠 | 移速 ×0.6（下限 ×0.5） | **复用** `EffectModifier`（待验证） |
| `stun` 眩晕 | 石锤 / 重剑（玩家侧；钝击专属） | 单次伤害 ≥ 目标最大生命 **10%** [试调] | **2000 AV**（v2 回填）；眩晕期间不刷新，结束后 **2000 AV 免疫** | 不叠 | 无（控制） | **新增**（禁行动 + 生成期过滤） |
| `bleed` 流血 | 锯齿剑（玩家侧） | 命中 35% [试调] 上 1 层 | **3400 AV**（每 800 AV 一跳，约 2 次挥剑） | 最多 3 层，刷新时长 | v1 不吃甲/抗性 | **新增**（层数 DoT） |

- 实现顺序（lead 结论 R6-3）：**迟缓 → 眩晕 → 流血**；**不先做通用 DoT 数据表**，等中毒/流血两个都在再抽象。
- **时长列已按 v2 现实口径回填**（1 AV = 1 ms，`docs/time-calibration.md`）：中毒 2400 / 迟缓 3000 / 眩晕 2000 / 崩山斩眩晕 800。
- 眩晕防永晕（lead 校准）：眩晕期间再次命中**不刷新**；眩晕结束后 **2000 AV 免疫**。阈值 10%（60×10%=6.0）——只有携带眩晕的钝击武器能过线（石锤 6.38 / 重剑 7.29）；锈铁剑 5.92 不触发。
- 流血 v1 口径：每层每 **800 AV** 造成目标最大生命 2% [试调]（不足 1 点按 1 点）；治疗类物品清 1 层。
- **怪物侧效果施加**（毒牙/蛛网/黏液/缠绕）：走 **「物种→状态」小表**，扩展现有 `poison_apply` 的硬编码模式（RULES §R4 骨架 #7）。**怪物侧眩晕/重击砍到后续**。
- **门类/特性 × 效果矩阵**（v1 数据校验用）：

| 目标 | 流血 | 眩晕 | 中毒 | 迟缓 |
|---|---|---|---|---|
| 人形 | ✓ | ✓ | ✓ | ✓ |
| 野兽 | ✓ | ✓ | ✓ | ✓ |
| 野兽 + `bloodless`（史莱姆） | ✗ | ✗ | ✓ | ✓ |
| 植物（食肉藤/菌人，默认 `bloodless`+`nerveless`） | ✗ | ✗ | ✓（腐坏） | ✓ |
| `arcane_construct`（第二层起） | ✗ | ✗ | ✗ | ✓ |

- **目标版**（旧讨论的流血示例，未拍板）：5 层，5000/4500/2800/2200/1500 AV 内造成生命上限 5/10/17/27/40% 的伤害，叠层刷新时长。v2 再上（见 RULES §R5）。

## 7. 层尾与推进

- **路径**：地图最深处 → 兽人营地 → 石门通道 → 楼梯（向下）。
- **守门锁**（lead 结论 R6-2）：**督军物理站位守楼梯**；生成器保证「楼梯在单通道尽头、督军相邻驻守、不漫游」；无锁系统，击杀即可通行。
- **督军行动（教程战，详见 `BESTIARY.md` §10.7）**：重斩 / 崩山斩（单体重击，可闪避，40 伤 + 眩晕 **800 AV**）/ 半血狂暴；玩家用「闪避」读倒计时反制，闪避成功后的下一次攻击触发「弱点击破」。**v2 校准**：督军攻 12→**10**；进入战区域前有 **1 次补给（+20 HP，一次性）**——不闪避期望约 74，容错很窄。
- **选择：已砍**（用户拍板）：督军半血直接进狂暴（保留阶段提示），不做「停手 ↔ 离开/击杀」分支；**不落跨层后果**。
- **v1 终点**：下楼 → **结束页 UI**（简短过场文字 + 结束画面）。第二层「魔法教学层」内容不做。
- 祭坛 = **Look 观察文本**（不做过场动画/对话树）。
