## 0. 一页速览

战斗 = **行动系统（时间）× 五域伤害（数值）× 效果/状态（持续）× 成长反馈（奖励）**。

每轮固定结算链（`ecs_core/src/system/mod.rs`）：

```
攻击意图 → 五域伤害 → 扣血 → 法术结算 → 投掷结算 → 投掷消耗 → 效果时长推进
→ 中毒 tick → 中毒施加 → 效果到期回收 → 死亡判定 → 经验/升级
→ 上限重算 → MP 回复 → 视野/记忆 → 占用图 → 格索引 → 治疗泉 → 事件缓冲交换
```

一句话口径：

- **时间**：AV 制；一个行动耗时 = 基础耗时 ÷ 速度。
- **命中**：伤害必中，无命中/闪避【已实现】。
- **伤害**：`max(1, 基础 × 增伤 × 暴击 × 护甲 × 抗性)`。
- **暴击**：加成型（`1 + 暴击伤害`），不是独立倍率。
- **资源**：HP 只靠消耗品与治疗泉；MP 每 10000 AV 回 1。
- **成长**：等级经验 + 武器成长（伤害换经验）+ 品质经验系数。

## 1. 时间与行动【已实现】

### 1.1 AV 公式

`AV = 基础耗时 ÷ clamp(速度, 0.25, 4.0)`

- 唯一入口 `balance::action_av`；速度 NaN 按 0.25 处理。
- 速度来自 `Stats` 的 `MOVE_SPEED` / `ATTACK_SPEED`（基准 1.0），可被装备/状态/地形修正。
- 地形修正只取**脚下格**：踏入减速格的当步不变慢，下一步才慢（DsnE12 的已知代价）。

### 1.2 基础耗时表

| 行动 | 基础耗时 | 速度 | 备注 |
|---|---|---|---|
| 近战 | 主手武器 speed（空手 300） | 攻速 | 武器覆盖基础耗时 |
| 移动 | 300 | 移速 | |
| 投掷 | 190 | 固定 | 不吃速度 |
| 施法 | `spells.json` 的 cast_av（当前 600） | 固定 | 不吃速度 |
| 等待 | 800 | 固定 | |
| 怪物追击 | 250 | 移速 | |
| 怪物逃跑 | 250 | 移速 | |
| 怪物游荡 | 500 | 移速 | |

> 当前玩家移速=攻速=1.25 是 Phase D 迁移映射产物；GAME 重校时应回 1.0【待重校】。

### 1.3 行动六阶段（DsnE8）

生成（只 spawn 候选）→ 仲裁（每 actor 至多一个）→ tick（推进计时器）→ 校验（保活 + 定案 + 预留格）→ 执行（唯一落地器）→ 完成（回收 + 行动状态回转）。

- 校验：**保活**对所有待执行行动生效；**定案**只对到点行动做。
- 预留格：校验阶段当场占格，同一轮不会两人抢同一格。
- 失败语义：移动被挡 = 失败；追击/逃跑/游荡被挡 = 原地仍成功；攻击前置不成立 = 失败；等待无校验器 = 永远成立。

### 1.4 玩家命令

| 命令 | 行动 | 说明 |
|---|---|---|
| Move | 移动 / 攻击 | 8 方向；目标格有怪 = 声明攻击 |
| Wait | 等待 | |
| Cast{slot} | 施法 | 生成期要求视野/射程内至少一个敌人（否则拒绝命令、不生成行动）；到点后校验期重选最近敌人 |
| Throw{dx,dy} | 投掷 | 目标是格子，落点必中 |
| Descend | — | 不是行动，无 AV |
| 背包动作（装备/卸下/丢弃/使用/拾取/搜刮） | — | 不占 AV，不走行动链 |

### 1.5 怪物决策

- 优先级：**Flee > Chase > Wander > Wait**（对应 -200 > -100 > -50 > 0；同优先级按实体 id 定平局，保证可复现）。
- 能力由怪物模板授予：Chase / Flee / Wander / Wait；现有八种怪已按内容轮分化（鼠 = 无追击，蝎 = 无逃跑，其余完整）。
- 逃跑滞回：HP 占比 < 25% 进入、≥ 30% 退出。
- 追击保活：看不见且无最后已知位置 → 取消。
- **AI 原语只有这四种**【已实现】；远程/施法/召唤/结群【空缺】。

## 2. 伤害管线【已实现】

### 2.1 近战五域

```
base = 攻击力 + min(力量, 力量上限) × 0.5
最终 = max(1, base × 增伤域 × 暴击域 × 护甲域 × 抗性域)
```

| 域 | 公式 | 说明 |
|---|---|---|
| 增伤域 | `1 + 伤害加成` | |
| 暴击域 | 暴击 ? `1 + 暴击伤害` : 1 | 暴击判定：暴击率 > 随机数 |
| 护甲域 | `4 ÷ (有效防御 + 4)` | δ=4；负防御按 0 |
| 抗性域 | `1 − clamp(物理抗性, 0, 0.75)` | 上限 75% |

- 下限在五域乘积之后取 `max(1)`；基础值不单独设限。
- NaN 归一为 0（防御、抗性、求和值）；`+∞` 保留。

### 2.2 力量与力量上限

- 力量上限 = 主手武器基础上限 + 武器成长加成；空手 4。
- 现有武器上限：锈铁剑 6 / 石锤 10 / 匕首 3 / 空手 4。
- **力量目前没有内容来源**（无物品/升级/状态给力量）→ 玩家恒为 4.0，于是 `min(力量, 上限) × 0.5` 恒为 2：剑 6 / 锤 10 的上限完全不生效，只有匕首 3 会真正压低力量项。用户已指出，列为待补（内容侧补来源，或删词条）。

### 2.3 投掷（DsnE28）

- 同构五域但只取四域：增伤 / 暴击 / 护甲 / 抗性；**基础来自投掷物，不吃攻击力与力量**。
- 射程 Chebyshev ≤ 5；视线阻挡 = **Wall / Stalactite / HangingVine / CoralReef**（`blocks_vision = true` 的四种地形）；落点必中；副手持投掷物，消耗 1 颗。
- 楼层成长当前常量 0（预留）【空缺】。
- 只做玩家侧；怪物投掷/远程【空缺】。

### 2.4 数据来源：StatId + Modifier（DsnE10）

- **12 项词表**：attack / defense / move_speed / attack_speed / crit_rate / crit_damage / max_health / max_mana / strength / damage_bonus / physical_resist / magic_resist（各有 [min,max] 与默认值）。
- 修正器四来源：`Intrinsic` 先天 / `Equipment` 装备 / `Status` 状态 / `Terrain` 地形。
- 求值五步：base → 收桶 → 过滤「无视来源」→ 按 StatId 折叠 → 纯函数。
- 折叠 = `(base + ΣAdd) × ΠMultiplyBase × ΠMultiplyTotal`（三算子折叠顺序是 DsnE22 ②a 的**已定设计**，不是暂定；GAME 不重复公式细节）。
- 规则层**永不出现**「若带了某装备则……」这类分支；「无视某类来源」是数据（`ignored` 列表）。
- 加新属性 = 改词表代码 + 数据。**设计稿里不能把 StatId 之外的新属性当已存在。**

## 3. 生命、法力、状态

### 3.1 上限与恢复【已实现】

- `max_hp = 80 + 8×(等级−1) + max_health 修正`；`max_mp = 12 + 2×(等级−1) + max_mana 修正`，最低 1。
- 上限唯一写者 `apply_maxima`；升级只重算上限、**不回满**。
- 出生回满；治疗泉每层 1 个、+12 HP、距出生点 4–10 格、满血不消耗。
- MP：每 10000 AV 回 1 点，满池不攒。
- 存档只存当前值，不存上限。

### 3.2 效果与状态【部分】

- 架构：效果 = 世界实体；三种落点——actor 拥有的持续效果（级联消失）、装备（不级联，人死掉地）、格子效果（格索引，每格一个实体）。
- 统一时长 `EffectDuration`（AV），唯一回收入口 `expire_effects_system`；payload 系统只改数据、不 despawn。
- 效果通过 `Modifier` 进规则，不改规则函数；「无视某来源」= `IgnoresSource` 过滤桶。
- **已实现状态只有中毒**：蝎子攻击施加；每 400 AV 跳 1 次、共 3 次；每跳 `max(1, 2×(1−魔法抗性))`；重复命中刷新不叠层。
- 【已成文·未实现】护盾（防御 `5 + 熟练度×2`，熟练度 1 时即 +7——**前提是「学会时熟练度=1」**；Gm6 现文未写死这个初值，待写 GAME/Gm6 时确认；MP 5；持续 1000 AV）/ 狂暴（攻击 `5 + 熟练度×2`，同左；MP 5；1000 AV）——公式见 GAME Gm2 技能伤害表，数值见 Gm5 buff 表，学习方式见 Gm6 卷轴。
- 【已成文·未实现】技能卷轴与熟练度（Gm6）：治愈/护盾/狂暴；首次使用学会，熟练度 +1；数值含法术精通与熟练度。

## 5. 成长与奖励【已实现】

### 5.1 经验

- 升级需求：`exp_to_next_level(level) = 25 × 等级^1.5 + 10 × 等级`（返回 f64，**未取整**；溢出按 `> 0` 连升）。
- 怪物经验：`round(exp_base + (楼层−1) × exp_per_floor)`（按物种模板）。
- 升级：溢出保留、可连升；只重算上限不回满；写升级事件。

### 5.2 武器成长

- 实例状态 `WeaponProgress{level, exp}`；蓝图 `growth{max_level, attack_per_level, strength_cap_per_level, exp_base}`。
- **只有近战命中**（`AttackEvent` → `apply_damage_system`）给主手武器经验：`伤害 × 品质经验系数`；法术/投掷伤害直接扣血，**不涨武器经验**。
- 门槛 = `exp_base × 等级^1.5`；可连升；满级停。
- 品质系数：粗劣 1.25 / 普通 1.0 / 精良 0.85 / 稀有 0.7 / 史诗 0.55 / 传说 0.4。
- 升级只加攻击与力量上限；断点副词条/附带效果【空缺】。

### 5.3 装备与掉落（战斗输入）

- 装备进身体七部位；属性走 Modifiers；武器有 speed / strength_cap / growth；容器与重量见 DsnE18/20。
- 怪物掉落与尸体装备按模板（Gm7）；每条掉落独立掷概率。
