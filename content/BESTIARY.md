## 1. 已拍板（用户 m00304 / m00317 / m00321）

- **命名**：总称「生物」；`生物 · 态度：友善/中立/敌对`。
- **态度三态**（对玩家）：
  - **友善**：不主动攻击，也不被动反击。
  - **中立**：被动反击；可因规则变化转换为敌对。
  - **敌对**：主动攻击。
- **仇恨系统**：需要做（已落地 DsnE29，见 §3）；属**目标选择层**，不新增行动原语。
- **门类方案甲**：四大门类 = 魔法造物 / 人形生物 / 野兽 / 植物。归属疑难解法：**亡灵 = 魔法造物 × 不死**、**矿灵 = 魔法造物 × 地脉**、**史莱姆 = 野兽 × 原生**。门类回答「它是什么做的」，特性回答「它怎么活、怎么打」。
- **智力五档**：0 无智 / 1 兽性 / 2 部落 / 3 守卫 / 4 策略。**设定智力就是 AI 天花板**。
- **实现暂缓**（用户 m00321）：先把内容定清楚，不急着写代码。

## 3. 仇恨系统候选

- **A 单目标记忆**（推荐第一章）：生物记「目标 + 最后攻击者」；脱战 = 离开领地 / 超时 / 跟丢。骨架 = 一个 `Aggro`/`ThreatTarget` 组件 + 脱战系统。
- **B 威胁值表**：每个目标一条威胁值（伤害 / 治疗 / 挑衅累加，随时间衰减），取最高者。有多目标、召唤物、队友时才值得。骨架 = 组件 + 事件 + 衰减系统。
- **C 感知 + 群体仇恨**：在 B 上加视野 / 听觉 / 气味通道、同群共享、警戒传播（一只发现→整群敌对）。适合群猎、营地、巢穴。
- **现状（lead m00352）**：威胁表已落地（DsnE29，commit 2a69176）——`Aggro` 威胁表 + 统一伤害出口 `DamageTakenEvent`；群体仇恨/警戒传播预留 `GroupId`/`AlertEvent` 扩展路径。
- 建议：第一章直接用已落地的**威胁表**（对应候选 B）；轻量单目标记忆（A）不再需要；群体仇恨（C）在需要群猎/营地时再上（走 `GroupId` + 同群记录）。
