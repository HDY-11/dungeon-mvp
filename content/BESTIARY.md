# BESTIARY — 生物设计（第一层 v1.1）

> 状态：**草案 v1.1**；框架已拍板（门类方案甲 / 三态度 / 智力五档 / 仇恨系统），第一层 8 种 + 1 精英生物卡已按 v1.1 裁剪修订。
> 非正典；数值标 **[试调]**，只进内容草案 / GAME，不进 DESIGN。
> 本版变更：史莱姆门类矛盾修正（无血/无神经改为特性）、掉落表去掉材料、AI 砍到基础版、督军数值按 LAYER1 §12 复核。

## 1. 已拍板（框架，术语不掉头）

- 总称：**生物**（不叫敌怪/怪物）。
- 态度三态：**友善**（不主动攻击、也不被动反击）/ **中立**（被动反击，可因规则转敌对）/ **敌对**（主动攻击）。
- **仇恨系统需要做**：已落地 DsnE29——`Aggro` 威胁表 + 统一伤害出口 `DamageTakenEvent`；群体仇恨/警戒传播预留 `GroupId` / `AlertEvent`。
- 门类方案**甲**：四门类不动（`beast` / `humanoid` / `plant` / `arcane_construct`）；生态来源（原生/变异等）作**特性**细分，不新增门类。
- 智力五档采纳（0 无智 / 1 兽性 / 2 部落 / 3 守卫 / 4 策略）。
- **实现暂缓**：先把内容定清楚，不急着写代码；第一层 v1.1 只裁剪最小 AI。

## 2. 门类与特性

| 门类 | 说明 | 第一层 |
|---|---|---|
| `beast` 野兽 | 自然生物；按本能行动 | ✓（巨鼠/蝙蝠/穴居蛛/史莱姆） |
| `humanoid` 人形生物 | 有社会与工具 | ✓（兽人斥候/蛮兵/督军） |
| `plant` 植物 | 植物/真菌类 | ✓（食肉藤/菌人） |
| `arcane_construct` 魔法造物 | 魔法驱动 | ✗（第二层起） |

| 特性 trait | 效果 | 谁有 |
|---|---|---|
| `bloodless` 无血 | 免疫流血 | 史莱姆、植物类 |
| `nerveless` 无神经 | 免疫眩晕 | 史莱姆、植物类 |
| `native` 原生 | 生态来源标记（**不是门类**） | 史莱姆等 |

- 修正记录：v1 把史莱姆写成「野兽 × 原生」并声称野兽对流血/眩晕免疫——矛盾。v1.1 改为「**野兽 + `bloodless` + `nerveless`**」，矩阵按特性覆盖（见 LAYER1 §4）。

## 3. 智力档 → AI

| 档 | id | 行为 | v1 是否实现 |
|---|---|---|---|
| 0 | `mindless` | 无智：只会按固定模式移动/攻击（如史莱姆、食肉藤） | ✓ |
| 1 | `feral` | 兽性：追击/逃跑/游荡/等待 + 受击仇恨 | ✓ |
| 2 | `tribal` | 部落：会判断强弱、低血逃跑、可能结伴 | 部分（结伴/呼救砍到后续） |
| 3 | `guardian` | 守卫：守点、不漫游（督军） | 部分（督军靠生成约束驻守） |
| 4 | `strategist` | 策略：包抄/换位/利用环境 | ✗（后续） |

## 4. 态度 → 行为（v1 基础 AI）

| 态度 | 默认 | 受击后 | 机制 |
|---|---|---|---|
| 友善 | 游荡/等待；不攻击 | 仍不攻击（逃跑可选） | 玩家可攻击它 → 变敌对（仇恨） |
| 中立 | 游荡/等待；不主动追 | 记仇，转敌对并追击 | 受击仇恨 |
| 敌对 | 视野内追击；邻接攻击 | 继续追击 | 视野/仇恨 |

- v1 AI 只做：Flee / Chase / Wander / Wait + 受击仇恨（DsnE29）；**呼救、巡逻路线、召唤、leash、救援交互全部砍到后续**。

## 5. 仇恨模型

- 现行：`Aggro` 威胁值表 + `DamageTakenEvent` 统一入账（近战/法术/投掷都走同一出口）；目标选择按威胁值，平局按实体编号。
- 预留：`GroupId`（同群互相警戒）、`AlertEvent`（警戒传播）；v1 不实现。
- 内容侧约定：群体仇恨只作为**后续**设计，v1 生物卡一律按单体仇恨写。

## 10. 第一层敌怪候选 v0（待用户设计特色）

> 用户要求：敌怪**不建议简单化**——「可以做得少，但必须有特色」；特色由用户设计，本节只给**候选与特色种子**。
> 建议：普通 6 种 + 精英 1 种（督军保留）；下面给 8 个普通候选 + 2 个精英候选，可挑可换。
> 旧卡（§8）暂作 v1.1 占位，候选定案后重写。

**特色设计轴**（挑 1 条当主线，不要全占）

| # | 轴 | 要回答的问题 |
|---|---|---|
| A | 感知/触发 | 它什么时候发现你？（视觉/震动/光/水波/静止伪装） |
| B | 出招节奏 | 前摇多长？破绽在哪？玩家能不能预判？ |
| C | 攻击形态 | 单体/横扫/直线/拖拽/自爆/区域？ |
| D | 场地改造 | 它会改变战场吗？（网/孢子/塌方/水） |
| E | 防守结构 | 甲壳/部位/破防/背刺？哪种武器更好用？ |
| F | 残血与死亡 | 逃/停手/狂暴/自爆/尸体残留？ |
| G | 关系 | 同类应激/抢食/领地/对玩家的厌恶来源？ |
| H | 玩家应对 | 走位/换武器/破甲/绕过/借环境？ |

**验收标准**：每种敌怪必须有「一个必须换个打法」的理由。只是血更厚、伤害更高，就不算特色。
