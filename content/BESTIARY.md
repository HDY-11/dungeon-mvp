# BESTIARY — 生物设计（第一层 v1.1）

> 状态：**草案 v1.2**；框架已拍板（门类方案甲 / 三态度 / 智力五档 / 仇恨系统），第一层 8 种 + 1 精英生物卡已按 v1.1 裁剪修订；**v1.2 已按 TIME v2 模拟校准回填**（`docs/time-calibration.md`）。
> 非正典；数值标 **[试调]**，只进内容草案 / GAME，不进 DESIGN。
> 本版变更：督军攻 12→10、巨鼠攻 4→2 + 同框上限；攻速表改 v2 现实口径；补岩壳兽/孢子行者正式卡；效果时长按 1.7 s 挥剑周期重算。

## 1. 已拍板（框架，术语不掉头）

- 总称：**生物**（不叫敌怪/怪物）。
- 态度三态：**友善**（不主动攻击、也不被动反击）/ **中立**（被动反击，可因规则转敌对）/ **敌对**（主动攻击）。
- **仇恨系统需要做**：已落地 DsnE29——`Aggro` 威胁表 + 统一伤害出口 `DamageTakenEvent`；群体仇恨/警戒传播预留 `GroupId` / `AlertEvent`。
- 门类方案**甲**：四门类不动（`beast` / `humanoid` / `plant` / `arcane_construct`）；生态来源（原生/变异等）作**特性**细分，不新增门类。
- 智力五档采纳（0 无智 / 1 兽性 / 2 部落 / 3 守卫 / 4 策略）。
- **实现暂缓**：先把内容定清楚，不急着写代码；第一层 v1.1 只裁剪最小 AI。

## 2. 门类与特性

| 门类 | 说明 | 第一层 |
|---|---|---|
| `beast` 野兽 | 自然生物；按本能行动 | ✓（巨鼠/蝙蝠/穴居蛛/史莱姆） |
| `humanoid` 人形生物 | 有社会与工具 | ✓（兽人斥候/蛮兵/督军） |
| `plant` 植物 | 植物/真菌类 | ✓（食肉藤/菌人） |
| `arcane_construct` 魔法造物 | 魔法驱动 | ✗（第二层起） |

| 特性 trait | 效果 | 谁有 |
|---|---|---|
| `bloodless` 无血 | 免疫流血 | 史莱姆、植物类 |
| `nerveless` 无神经 | 免疫眩晕 | 史莱姆、植物类 |
| `native` 原生 | 生态来源标记（**不是门类**） | 史莱姆等 |

- 修正记录：v1 把史莱姆写成「野兽 × 原生」并声称野兽对流血/眩晕免疫——矛盾。v1.1 改为「**野兽 + `bloodless` + `nerveless`**」，矩阵按特性覆盖（见 LAYER1 §4）。

## 3. 智力档 → AI

| 档 | id | 行为 | v1 是否实现 |
|---|---|---|---|
| 0 | `mindless` | 无智：只会按固定模式移动/攻击（如史莱姆、食肉藤） | ✓ |
| 1 | `feral` | 兽性：追击/逃跑/游荡/等待 + 受击仇恨 | ✓ |
| 2 | `tribal` | 部落：会判断强弱、低血逃跑、可能结伴 | 部分（结伴/呼救砍到后续） |
| 3 | `guardian` | 守卫：守点、不漫游（督军） | 部分（督军靠生成约束驻守） |
| 4 | `strategist` | 策略：包抄/换位/利用环境 | ✗（后续） |

## 4. 态度 → 行为（v1 基础 AI）

| 态度 | 默认 | 受击后 | 机制 |
|---|---|---|---|
| 友善 | 游荡/等待；不攻击 | 仍不攻击（逃跑可选） | 玩家可攻击它 → 变敌对（仇恨） |
| 中立 | 游荡/等待；不主动追 | 记仇，转敌对并追击 | 受击仇恨 |
| 敌对 | 视野内追击；邻接攻击 | 继续追击 | 视野/仇恨 |

- v1 AI 只做：Flee / Chase / Wander / Wait + 受击仇恨（DsnE29）；**呼救、巡逻路线、召唤、leash、救援交互全部砍到后续**。

## 5. 仇恨模型

- 现行：`Aggro` 威胁值表 + `DamageTakenEvent` 统一入账（近战/法术/投掷都走同一出口）；目标选择按威胁值，平局按实体编号。
- 预留：`GroupId`（同群互相警戒）、`AlertEvent`（警戒传播）；v1 不实现。
- 内容侧约定：群体仇恨只作为**后续**设计，v1 生物卡一律按单体仇恨写。

- 攻击 AV 公式：`AV = 攻击基准 ÷ 攻速`；玩家 = 武器 `speed_ms` ÷ 玩家攻速；怪物空手基准 800，持械用 `MonsterTemplate.weapon_speed_ms`（None→800）。
- **效果时长 v2**（按 1700 AV 挥剑 ≈ 1–2 轮）：流血 **3400**、中毒 **2400**、迟缓 **3000**；玩家武器眩晕 **2000**、崩山斩眩晕 **800**。
- 免疫按门类/特性矩阵（LAYER1 §4）：`bloodless` 免疫流血、`nerveless` 免疫眩晕；植物默认两条都有；魔法造物在 v1 不出现。
- v1 怪物侧只施加 `Poison` / `SlowMove`（对玩家：人形无特性，全部 ✓）；流血/眩晕只由玩家武器施加。

### 10.7 督军教程战 v1.2（闪避 / 弱点击破版，已拍板方向）

> **已拍板（用户，经 lead）**：①崩山斩 = **A 单体重击、可闪避**（不做 AOE）；督军不需要蓄力打断框架，用长 AV 攻击 + 事件栏倒计时读招即可。②**砍掉「杀/放」叙事与选择**，半血直接进狂暴（保留阶段提示）。③闪避改为**「层尾小 boss 战授予」**：开局不可用；进入督军战区域时事件栏提示并解锁（固定键 `f`）；v1 只在此战可用，不做战斗中途多阶段解锁。④**突进蜥后置**；v1 新原语 = 动态格子效果 + 闪避行动（共 2 个）。
> 成本（lead）：合计 **3.5–6 天**。lead 已核实回合制落点：事件栏显示敌人攻击倒计时；闪避是玩家下一个行动，动作完成到该次攻击落地之间是窗口，落地时按「移速 + 提前量」掷骰；攻击在闪避完成前落地 → 没赶上（不可闪避）。

**督军三件套**（lead 修正版）

| 行动 | 形态 | 前摇/AV | 效果 [试调] | 反制 |
|---|---|---|---|---|
| 重斩 | 单体近战 | 1700 AV | 常规高伤（攻 10 → 约 5–6） | 侧移/等破绽 |
| 崩山斩（大招） | 单体重击（A 方案，可闪避） | 长 AV，事件栏倒计时 | 40 伤害 + 眩晕 **800 AV**（v2 校准：600→800） | **闪避**；闪避成功 → 弱点击破（演示 100%） |

> **A 已拍板**：崩山斩 = 单体重击、可闪避；AOE 版本不做（「范围攻击不可闪避」的口径留给以后的横扫类招式）。

**闪避（玩家动作，新原语；层尾授予）**
- 开局不可用；进入督军战区域时事件栏提示并解锁固定键 `f`；v1 只在此战可用。不做战斗中途多阶段解锁。
- 动作 AV = **300 / 移速** [试调]；气力消耗 **30–40**（上限 100，初始满，每 1000 AV 回 10）。
- 成功率（**v2 收紧版**，lead 校准）：`p = clamp(0.05 + 0.35×(移速/参考速) + 0.45×提前量比例, 0.05, 0.95)`；提前量比例 = (攻击剩余 AV − 闪避动作 AV) / 攻击总 AV；教程演示覆盖为 **1.0**。旧公式（0.15+0.55×速度+0.30×提前量）在移速 1.0、提前量 0 时 p=0.70，偏慷慨。
- 范围攻击不可闪避（v1 崩山斩为单体，无冲突）。
