# 层 → 区块地图方案（第一层）

> 状态：**核心已拍板**（128×128 / 方案 A / 层尾门约束）；每层区块数待实测评估；细节待定
> 依据：用户「地图是层→区块；80×60 只是一块区块；倾向方形区块；255×255 指区块尺寸」
> 关联：`CONTENT.md`（层结构与难度）、`LAYER1.md`（第一层内容）、`RULES.md` §R3.1（层内区块系统评估）

## 0. 一句话

第一层 = **若干方形区块 + 连接口**。区块是「一张 Map」的最小单位，层是区块网；一块 = 一个群系的箱庭。
建议区块 **128×128 格**，不是 255×255。

## 1. 区块尺寸：128×128（已拍板）

| 尺寸 | 格数 | 视窗数（40×20） | 步行时间* | 判断 |
|---|---|---|---|---|
| 80×60（现状） | 4,800 | 6 | ~10 min | 太小，一步一块 |
| 96×96 | 9,216 | 11.5 | ~20–25 min | 下限 |
| **128×128（推荐）** | 16,384 | 20.5 | ~35–45 min | 一层 4–6 块 ≈ 全探索 4–6 h |
| 160×160 | 25,600 | 32 | ~60 min | 上限偏高 |
| 255×255 | 65,025 | 81 | **~2.2–2.5 h** | 单块吃掉全部预算，否 |

\* 步行按 0.4 s/格（`TIMING.md`）、可走率约 50%、覆盖 70% 估算，不含战斗与搜索。

理由：255×255 一块就要 2 小时以上纯走路，FOV 10 下 81 个视窗的空旷感填不满；128×128 刚好是「一个箱庭的探索单元」，4–6 块凑满 4–6 h 全探索，也匹配「每块一张 Map + 连接口切图」的落地方案（R6 #1）。
**已拍板（用户 2026-11-11）：接受 128×128。**
[试调] 若实测步行占比过高，两个旋钮：块尺寸 96–112、移动 300–350 AV/格。

## 2. 层 = 区块网

- 排布：方格网、4 邻接（N/E/S/W）；`*` = 无区块 = 实心（不可见、不可入）。
- 每层区块数**不写死**：现按 4–6 块设计，**待实现/实测评估后再定**（用户：4–6 块可能要根据实际情况评估）。
- **0 号块 = 表层洞窟**，固定；玩家出生在这里。
- 难度 = 区块图上到 0 号块的 BFS 距离（0/1/2/3…）+ 随机扰动 ±1；距离带决定群系、生物档、结构档。
- 层尾 = BFS 距离最大的区块；其楼梯厅 = 层尾门（v1 终点）。
- 跨块：从连接口进入（§4）；每块 RNG = `(map_seed, floor, cx, cy)` 派生，进程内重进按同 seed 重生成（v1 不做状态保留，按 RULES §R3.1 口径）。

## 3. 两群系怎么放（方案 A 已拍板）

**方案 A（推荐）：一块 = 一个群系。**
两群系 = 相邻两块（表层 ↔ 水蚀），经连接口相连；连接口两侧各 8–10 格做地形混合过渡带（Surface/ShallowWater 渐变）。
- 距离 0：表层洞窟；距离 1：表层 70% / 水蚀 30%；距离 ≥2：水蚀为主。
- 优点：单块生成参数单一、密度与结构可控；缺点：群系切换发生在切图瞬间，需要过渡带补「渗入感」。

**方案 B（fallback，若 v1 只做一块）：** 单块内分区——靠入口 60% 表层、远端 40% 水蚀，沿一条不规则曲线分界，边界 8–10 格过渡带；结构按分区摆。
**不推荐**单块硬拼两套完整地形参数：生成器复杂度翻倍，且与「层→区块」结构重复。

## 4. 连接口

- 位置：每条相邻区块共享边一个连接口，位于边中点 ± 随机偏移 ≤8 格；每块 1–4 个（0 号块至少 1，层尾块至少 1）。
- 形态：两侧各 3 格宽通道 + 2×2 洞口小房间，保证箱庭感与视线引导。
- 生成期确定、记录进 block 数据（切图与存档坐标用）。
- 层尾块若只有一个连接口：从该口到楼梯厅必须是必经路（守门锁 = 督军驻守）。

## 5. 4 个生成结构怎么摆（v1）

| 结构 | 尺寸档 | 群系 | 每层 | 摆放规则 |
|---|---|---|---|---|
| 药草圃 | 微 | 表层 | 1–2 | 房间边缘/走廊凹处；距入口 15–40 格 |
| 矿脉簇 | 微 | 水蚀 | 1–2 | 走廊尽端；与水蚀地形相邻 |
| 兽巢 | 中 | 表层 | 1–2 | 独立房间群；距入口 20–60 格；刷斥候/蛮兵 |
| 地下泉 | 中 | 水蚀 | 1–2（至少 1 个） | 距入口 ≥40 格；不在层尾门口 10 格内 |
| 守门厅 | 大 | 任意 | 1（只在层尾块） | 末块单通道尽头；督军驻守，楼梯在其后 |

- 通用约束：结构之间 ≥12 格、不压连接口、不堵唯一通路；同类结构不在同一块重复。
- 每块 1–2 个结构（v1 共 4 种），一层合计 6–10 个。
- 微结构允许「看一眼就走」（Look 观察文本，不强迫进入）。

## 6. 层尾门与入口的相对位置

- 0 号块出生点：块内第一个房间（沿用现状）；0 号块只开 1–2 个连接口。
- 层尾块：从「进入该块的连接口」到楼梯厅的 BFS 距离 ≥ 块对角线 55%（128×128 下约 ≥100 格）；楼梯厅 20×12，门前 3 格单通道，督军驻守。
- 不满足则重生成（最多 3 次）；仍不满足则退回「离入口最远房间」。
- 站楼梯按 `>` 下第二层（v1 终点）。

## 7. 密度与节奏（128×128 口径）

- 生物：每块 15–25（含精英 0–1），一层 60–120；栖息见 `LAYER1.md` / `BESTIARY.md`。
- 地面物品：每块 10–16 件（结构固定物 + 地貌随机）。
- 治疗泉：每层 2–3 个，分散在不同块。
- 单块全清预估 35–45 min（步行 25–35 + 战斗 5–10 + 搜索 3–5）。

## 8. 需要骨架

1. 区块图 + 连接口数据（block graph / ports）。
2. 切图入口 + 存档坐标（当前区块坐标 + 块 seed）——按 RULES §R3.1「先做换图 + 离开重置 + 每区块 RNG」。
3. 生成器按 `(seed, floor, cx, cy)` 派生 RNG；难度带查表。
4. 生成期跨块校验（出生点/层尾门/结构不堵路）。
