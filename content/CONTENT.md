## 0. 一句话

传统奇幻 RPG 的表层之下是三重世界；勇者讨伐恶龙，而世界会随两个不可见的刻度（San / 灵感）改变面貌。第一章只做「干净的传统 RPG」——那是第二界最像真实世界的一层。

## 1. 世界：三重

| 界 | 内容 | 力量线 | 状态 |
|---|---|---|---|
| 物质界 | 物品 / 装备 / 机械 | 造物（科技） | 远景（第一、三条线后做） |
| 意象界（幻象界） | 法术、法术书、法杖；物质与精神的交互产物 | 血肉（生物） | **第一章舞台** |
| 亚空间 | 神灵 / 灵魂 / 疯狂 | 灵知（神恩，或与神为敌） | 远景（第三条线） |

- 术语（未拍板）：物质界 / **意象界**（备选：幻象界、梦境）/ 亚空间（保留；备选：幽界、混沌海）。力量线：**造物 / 血肉 / 灵知**；「路线」→ **道途**。三个世界统一以「界」收尾。
- 第一章 = 第二界；灵感中平、San 偏高 → 世界呈现为普通奇幻 RPG。
- 四象限推演（未拍板，顺规则推出）：灵感低+San高=**凡尘**｜灵感低+San低=**盲者**｜灵感高+San高=**先知**｜灵感高+San低=**交感者**。第一章=凡尘。
- 第一章禁区：不点破 HP/MP 是界面、不点破三重世界（第一章做的东西后面要能被「重新解释」，不能被「否定」）。

## 2. 两条不可见刻度（用户 m00124）

- **San**：越低，灵魂越容易与亚空间**交感**（更像「灵魂与亚空间之间的那层膜/封条」，不只是精神状态）。
- **灵感**：越高，能看到的亚空间内容越多；**低灵感=物质，高灵感=精神**。
- 两值**玩家不可见**；世界面貌随二者变化；玩家通过**世界变化 / 自身变化 / 系统（UI）变化**三条通道察觉（用户 m00129）。
- HP/MP 仅在第二界有效、但非在第一/三界完全无效；由更本质的东西决定（用户 m00132，暂不设计）。
- 第一章按「干净的传统 RPG」处理，灵感/San 不生效（待用户最终确认）。

## 3. 玩家与叙事

- 身份：**勇者**；目标：**战胜恶龙**；动机：**「因为他是勇者」**（借来的动机，用户 m00139——类型替玩家写完前史，不演为何出发）。
- 剧情：**揭开真相 + 做出选择**；不同选择影响结局（用户 m00129）。叙事分章节。
- 第一章：**没有村庄**，简短开场后直接从洞穴开始（用户 m00149）。
- 量级：主线 1–2h；完全探索按 4–6h 内容设计（用户 m00152）。
- 风格：干净的传统 RPG 表层；**承袭式虚构**——不从头虚构，在已有类型套路上虚构（用户 m00132）。
- 底本素材库（候选，未拍板）：D&D / 日式勇者（DQ·FF）/ 托尔金 / 战锤奇幻 / 猎魔人 / 剑与魔法。四位「老师」的馈赠：**代价式严谨**（诡秘之主）、**涌现式丰富**（我的世界）、**乘法定律+单元剧**（原神）、**战力即立场+群像旅途**（崩铁）。
- 风格一句话：设定严谨到能推演，玩法丰富到能组合，叙事克制到不解释。

## 4. 第一章舞台（结构已定）

```
0 引子（简短介绍，无村庄）
→ 1 洞窟 · 外围群系（= 第一层）
→ 2 恶魔城 · 外围
→ 3 恶魔城 · 内部（进度锁密集 + 小 boss）
→ 4 恶魔城 · 核心（恶龙决战）
```

- **恶魔城 = 地名；地下城 = 玩法类型**；洞窟层 = 第一层。
- 除进度锁锁定的内容外，地图可自由探索（肉鸽）。
- **进度锁**（用户 m00156：以能力型为主，主要考验战斗能力）：建议改称「**守门锁**」——门由一场战斗打开；待用户确认。摆法候选：每段末一道 / 段内多道可跳可回头 / 混合。
- 量级与恢复来源：**挂起**（触发条件 = 战斗节奏定，用户 m00156）。

## 5. 第一层（洞窟层）结构（用户 m00310 / m00314）

- **形状**：区块网格图（示例：表层洞窟 / 水蚀 / 晶矿 / 废弃遗址 / 蘑菇 …）；`*` = **没有区块 = 实心岩壁**。
- **生成**：算法先铺出整片区块图，玩家横向移动时**按需动态生成**；区块与区块之间用**连接口**相连（箱庭式连通）。
- **固定**：第一个区块 = **表层洞窟**（也是普通区块，出生点所在）。
- **难度**：以「离出生区块的距离」为自变量 + 随机扰动的函数；距离按区块图 **BFS 步数**。候选：A 线性 / B 分带（近 0–2 / 中 3–5 / 远 6+，推荐）/ C 阶梯混合。扰动每区块由 seed+坐标确定一次，重进不重掷。
- **群系候选（暂定）**：表层洞窟、水蚀洞窟、晶矿洞窟、废弃遗址 **+ 生成结构**；蘑菇洞窟去留待定。
- **生成结构候选（12）**：
  - 微：矿脉簇（晶矿）、药草圃（表层/水蚀）、地下泉（全部）、石碑/壁画（废弃遗址）、矿工营地遗迹（晶矿）、巨兽骸骨（表层）
  - 中：兽巢（表层/水蚀）、坍塌矿道（晶矿）、陷阱长廊（废弃遗址）、精英巢穴（远距离）、捷径/暗道（全部）
  - 大/唯一：**层尾之门**（通往恶魔城；建议配守门锁）
  - 生成规则候选：每区块 0–2 个、一层共 8–15 个；距离带决定档位（近=资源/叙事，远=冒险/精英）；类型限量（泉 2–3、层尾门 1）；除层尾门外可绕过。建议先做 6 个：矿脉簇、药草圃、兽巢、石碑、捷径、层尾之门。
- **恶魔城段**：外围（庭院/断桥/枯井/外墙）→ 内部（大厅/回廊/书库/地牢/仪式厅候选）→ 核心（地下湖/龙骨王座/龙巢）。
- **待定**：区块内部形态（换图 vs 连续）、区块持久化、区块规模/总数、层尾门具体位置、蘑菇洞窟去留。
