## 1. 世界总览：三界与三道途

世界分作三重：**物质界**、**意象界**、**亚空间**，分别对应**科技**、**奇幻**、**精神**。

- 物质界：器物、装备、造物。
- 意象界：规则与幻象交织的中间层——第一款游戏的舞台。物质与精神在此交互，最像「真实世界」。
- 亚空间：精神与灵魂的领域。

玩家有三条道途：**造物**（器物与装备）、**血肉**（等级与肉身改造）、**灵知**（神恩，或与神为敌）。

- 第一章只走**奇幻线**（生物线，第二条道途）；第一、三条道途后做。
- HP/MP 归奇幻一脉；它们只在第二界（意象界）完全有效，由更本质的东西决定——暂不设计。
- 承袭式虚构：不从头虚构，在已有类型套路上虚构（D&D、日式勇者、托尔金、战锤、猎魔人、剑与魔法等底本素材库，见 §6）。

## 2. 两条不可见刻度（San / 灵感；第一章不启用）

- **San**：越低，灵魂越容易与亚空间交感（像灵魂与亚空间之间的那层膜/封条）。
- **灵感**：越高，能看到的亚空间之物越多；低灵感所见皆物质，高灵感所见皆精神。
- 两值**玩家不可见**；世界面貌随二者变化；玩家通过**世界变化 / 自身变化 / 系统（UI）变化**三条通道察觉。
- 四象限（推导，供后续章节用）：

|  | San 高 | San 低 |
|---|---|---|
| **灵感低** | **凡尘**：物质、安稳、看不见也触不到（第一章在这里） | **盲者**：看不见，却已被侵蚀 |
| **灵感高** | **先知**：看得见，不被牵走 | **交感者**：看得见，也被拉入 |

- 第一章**不做**（用户定案：先不做以减少负担，未来扩展难度不高）。

## 3. 玩家与叙事

- 身份：**勇者**；目标：**战胜恶龙**；动机：**「因为他是勇者」**（借来的动机——类型替玩家写完前史，不演为何出发）。
- 剧情：**揭开真相 + 做出选择**；不同选择影响结局。叙事分章节。
- 第一章：**没有村庄**，简短开场（已接下任务）后直接从洞穴开始。
- 量级：主线 1–2h；完全探索按 4–6h 内容设计（单次跑图 vs 多周目累计待定）。
- 风格：干净的传统 RPG 表层；承袭式虚构；「第一章做的东西，后面要能被重新解释，而不是被否定」（如 HP 可被重新解释为「存在度」）。
- 参考（影响较深）：《诡秘之主》=代价式严谨；《我的世界》=涌现式丰富；《原神》=乘法定律+单元剧；《崩坏·星穹铁道》=战力即立场 + 群像旅途。一句话风格：设定严谨到能推演，玩法丰富到能组合，叙事克制到不解释。
- 第一章**禁区**：不能点破 HP/MP 是界面；不解释勇者动机；不出现魔法体系。

## 5. 第一层区块结构（远景架构，v1 不做）

### 5.1 结构

- **层** = 一张由**区块**拼成的网：区块间有**连接口**；算法先铺整片区域标记，再按玩家位置**动态生成**当前区块。
- 玩家**横向移动**（相邻区块）；箱庭式区块 + 连接口。
- `*`（空）= 没有区块 = **实心墙壁**，不可通行。
- **固定第一个群系 = 表层洞窟**（普通区域）；其余群系随机。
- **难度** = 离出生区块的距离（BFS）+ 随机扰动 的函数；候选：A 线性 / B **分带**（推荐）/ C 混合。
- 当前实现仍是「一层 = 一张 80×60 地图 + 楼梯」；区块网=架构级新骨架（评估见 `RULES.md` §R3.1，v1 不做）。

### 5.2 群系与生成结构

- 第一层群系暂定：**表层洞窟 / 水蚀洞窟 / 晶矿洞窟 / 废弃遗址**（v1 只做前两个）。
- 生成结构 12 候选：**微**（药草圃 / 地下泉 / 矿脉簇 / 巨兽骸骨）、**中**（兽巢 / 坍塌矿道 / 陷阱长廊 / 石碑壁画 / 矿工营地 / 捷径暗道）、**大**（精英巢穴 / 层尾之门）。
- 生成规则候选：每区块 0–2 个；一层 8–15 个；距离带定档；同类型限量；除层尾之门都可绕过。
- 恶魔城段结构（后续）：**守门锁 / 楼梯 / 小 boss / 祭坛**；守门锁类型见 §4.1。
